# T8 · Pause bands and the session spine

**What to build:** a Pause renders as the weakest, dashed band attached to its
session, and a thin continuous spine under the bar keeps the session one object
across pauses — while a gap between two sessions has no spine.

**Blocked by:** T7 (LD-16).

**Status:** blocked

- [ ] A Pause inside a session shows as a dashed lowest-intensity band, never empty space.
- [ ] A spine joins the session's segments so it reads as one sitting.
- [ ] Two separate sessions show no connecting spine.
- [ ] A Pause never reads as study time (visually distinct from every study tier).
