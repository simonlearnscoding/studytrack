#wayfinder/research

## Question

What makes a study session feel shared, in products that already do this well
(Fiveable, Focusmate, Forest)? Surface concrete mechanics (timers, presence,
task visibility, celebration) worth borrowing for the Session card and the wider
Session feel. Informs ST-18.

## Answer

The shared feel comes from three cheap, stealable mechanics:

- **Shared, synced session timer** — Fiveable's countdown plus a "X people studying" counter.
- **One-line public intention** per person ("what are you working on") — Focusmate's greet-and-state ritual.
- **A living artifact + a check-in/celebrate beat** at session end — Forest's growing/dying tree, Focusmate's end-of-session check-in.

Skippable: native video, streamed audio/lofi, app-blocking, coins/economies — Discord already owns presence, and the rest is expensive or fragile for a small web dashboard.

Note: this reinforces the owner's call that the timer is _not the soul_ but a likely-later ingredient — several of these products lean on it, none need it to feel shared. The card's task visibility (ST-17) is the real carrier.
