# Task counts are public, task content is private

A member's task list is private — only its owner can read the titles or change
them — but the open/done **counts** are shown to the room. The list is private
because a task is a plan for oneself, not something to be judged on. The counts
are public because the room is social: output seen next to study time is what
keeps a group honest. The split serves both without exposing what anyone studies.
