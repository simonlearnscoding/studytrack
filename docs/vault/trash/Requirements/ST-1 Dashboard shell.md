# ST-1 Dashboard shell

One screen, two columns: **social** (wide, left) and **self** (narrow rail,
right). On narrow viewports they collapse into tabs.

Why: the product is social-facing, so the room is primary and the personal rail
carries the private motivation.

Open: the breakpoint; whether the tabs are labelled "Room" and "Me".
