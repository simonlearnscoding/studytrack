# ST-1 Dashboard shell

One screen, two columns: **social** (wide, left) and **self** (narrow rail,
right). On narrow viewports the self rail comes first — you, then the group —
as a plain stack, not tabs.

Why: the product is social-facing, so the room is primary on a wide screen, but
on a phone your own panel leads and the group follows. Everything else hangs off
this shell.

Blocked by: none.
